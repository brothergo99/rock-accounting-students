Question 17–18
第17題 EPS 陷阱 × 第18題 成本混入概要
第17題 EPS 計算 🪤 定義陷阱

「綜合損益」≠「本期淨利」

陷阱
題目給綜合損益 = 100萬，但 EPS 分子應用本期淨利，不是綜合損益
S1
本期淨利 = 綜合損益 − 其他綜合損益
100萬 − 20萬 = 80萬
S2
加權平均股數：
10萬股 × 3/12 + 14萬股 × 6/12 + 12萬股 × 3/12
= 2.5 + 7 + 3 = 12.5萬 → 125,000股
✓
EPS = 80萬 ÷ 125,000 = 6.4 元

老師批評：故意用「綜合損益」這種象牙塔講法來迷惑考生——實務上大家都說「本期淨利」。

第18題 料工費成本 🪤 科目混淆

成管會內容闖入「會計概要」

已知條件
主要成本
DM + DL = 9萬
加工成本
DL + OH = 7萬
DM：OH = 5：3（這比例在實務根本不存在！）
S1
相減消去 DL：9萬 − 7萬 = DM − OH = 2萬
S2
5:3 差2等份 = 2萬 → 1等份 = 1萬
DM = 5萬，OH = 3萬
S3
回推 DL：9萬 − 5萬(DM) = 4萬
✓
總製造成本 = 5萬 + 4萬 + 3萬 = 12萬

老師批判：這是成管會第一章內容，根本不該出現在概要！5:3比例在實務毫無意義。腦筋轉不過來可直接放棄。

第19題 CVP 分析 🪤 最後一步陷阱

算出邊際貢獻就開心作答 → 直接失分

固定成本
5萬

20%

60元
S1
稅後→稅前淨利還原：6萬 ÷ 0.8 = 7.5萬
S2
總邊際貢獻需求：7.5萬 + 5萬(固定) = 12.5萬

第20題 現金流量 ⏱️ 極耗時

9 個加減項目，一錯全錯

判斷原則：「貸方方向 → +，借方方向 → −；非現金/非營業項目特別處理」

折舊費用（非現金支出）
+
處分資產利益（非營業項目）
−
應收票據減少（貸方）
+
應收帳款增加（借方）
−
存貨增加（借方）
−
預付費用減少（貸方）
+
應付帳款增加（貸方）
+
應付利息增加（貸方）
+
支付所得稅
−

老師親測：AI 也把「處分資產利益」反推邏輯搞錯。選擇題卻要 9 個加減，按錯一個鍵整題泡湯，零容錯空間。

Essay Question · 17 分
申論題：固定資產入帳 × SYD × DDB × 資產減損（爆難·四階段陷阱）
😡
老師評語：「爆難、完全瞎搞、沒有打算讓大家及格」。只要第一階段入帳成本算錯，後面三個階段全部 0 分。
第一階段 入帳成本認定

什麼可以計入成本？

基礎
機器定價 60萬 × 95折 = 57萬
現金折扣符合條件 → 再 × 98%
57萬 × 98% = 558,600元
加項
運輸費 + 保險費 + 安裝費 → 全部可計入
558,600 + 運 + 保 + 安 = 584,600元
✗ 運送碰撞修理費——不計入（屬意外損失）
✗ 舊機器拆除費——不計入（故意混淆土地建物拆除的處理方式）
✗ 人員操作訓練費——不計入（實務上根本包在設備款，極刻意的陷阱）
第二-四階段 SYD → DDB → 減損

折舊地獄時間軸

X3年 7月1日
年中購入，使用年數合計法（SYD）
耐用8年，分母 = 1+2+…+8 = 36
X3年折舊 = 584,600 × 8/36 × 6/12
（跨年度必須切半→除不盡→考場恐慌點）
X4年（全年）
X4年折舊分兩段：前半 8/36、後半 7/36
（因7/1起算，每年折舊橫跨兩個年度比率）
X5年 1月1日 ← 三改同時發動
① 殘值增加
② 耐用年限延長 1年
③ 折舊法改為雙倍餘額遞減法（DDB）
─────────────────
X5年初帳面價值 ≈ 404,241元
剩餘年限：原6.5年 + 1年延長 = 7.5年
DDB折舊率 = 2 ÷ 7.5（不考慮殘值！）
X5折舊 = 404,241 × 2/7.5 = 107,798元
X6年底 → 資產減損測試
算出X6年折舊後，X6底帳面價值 ≈ 217,391元
可回收金額：max(市價18萬−處分成本3萬, 使用價值20萬) = 200,000元
減損損失 = 217,391 − 200,000 = 17,391元
Key Takeaway
這次考題教會我們的事

✅ 三個計算公式要背熟

EPS 分子
本期淨利 = 綜合損益 − OCI
CVP 逆推
稅後→稅前 ÷(1−稅率)→ +固定成本 ÷ 銷量 → 邊際貢獻 → +變動成本 = 售價
DDB 折舊率
2 ÷ 剩餘年限（不考慮殘值）

🪤 四大必死陷阱

  • Q17題目說綜合損益，先扣OCI才是EPS分子
  • Q19算出邊際貢獻 40元不是答案，要再加變動成本
  • 申論訓練費、拆除費、修理費不計入入帳成本
  • 申論SYD 年中購入必須跨年度切割比率

🧠 現金流量速查

間接法判斷口訣
+ 加回：折舊 · 資產損失 · 負債增加 · 資產減少
− 扣除：資產增加 · 負債減少 · 非營業利益
特別記：處分利益 → 移到投資活動，所以「−」
