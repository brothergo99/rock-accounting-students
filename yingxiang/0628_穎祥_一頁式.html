🕹 夾娃娃機（選物販賣機）：稅務生態全解析

基本稅務規範
正式分類：選物販賣機。機台須貼登記證。營業額達 8 萬元起徵點 → 必須辦營業登記、繳 5% 營業稅 + 繳納營利事業所得稅。
同業競爭（打台）惡性循環
台主從淘寶/蝦皮進誘人商品 → 其他台主低成本夾走（打台）→ 被迫加高擋板、改夾子 → 嚇跑純娛樂客人
⚠ 意想不到的娛樂稅！
選物販賣機本屬商品販售，理應無娛樂稅。但加高擋板 → 需要「技術」才能夾取 → 稅局認定具「娛樂性質」→ 強制課娛樂稅。稅局人員會實際到場測量擋板高度，絕不客氣。

🌐 網紅稅務難題：從匯款到 IP 位址

早期稅局困境
YouTube 是美國公司 → 廣告分潤匯入外幣帳戶 → 被視為境外所得 → 美國公司不配合提供台灣創作者收入資料 → 稅局抓不到。
關鍵突破：屬地主義
課稅核心不是「所得稅」，而是「營業稅」。營業稅看的是消費行為發生地——只要觀眾在台灣境內觀看影片或打賞，這筆交易就在台灣發生，應課台灣的 5% 營業稅。
判定武器：IP 位址
觀眾的網路 IP 位址決定課稅地。IG / YouTube 後台洞察報告可精準顯示粉絲來源。銀行收到 YouTube 匯款超過 5 萬元 → 主動詢問資金來源 → 稅局有權調閱金融機構收款資料。
Tax Strategy · 國稅局的終極戰略
放長線釣大魚：網紅節稅數據反成稅局的精準武器

🎣 一石二鳥：外銷零稅率反將稅局一軍的迴旋棒

①
稅率結構：境內收入課 5% 營業稅；境外收入適用「外銷零稅率（0%）」。
②
大網紅的節稅動機：為了少繳稅，主動向 YouTube 申請「境內 vs 境外 IP 收入占比」詳細數據，向稅局申報以扣除境外部分。
③
稅局反將一軍：當眾多網紅紛紛將 YouTube 的境內收入數據交出，國稅局把所有人的境內收入加總，精準算出 YouTube 在台灣的「總銷售額」——證據確鑿！
④
境外平台就範：年銷售額超 60萬台幣 → 必須在台辦稅籍登記、繳納 5% 營業稅。掌握營業稅 = 收入所得再也跑不掉。

🌍 境外電商全數就範：稅局戰果

根據「境外電商課稅專區」，以下國際巨頭全數在台設立統編、乖乖繳稅：

📱 TikTok 🔍 Google 📘 Meta (FB/IG) 🎵 YouTube 🚗 Uber 🎬 Netflix 🏠 Airbnb
關鍵門檻：境外平台在台年銷售額 > 60萬 台幣 → 強制在台設稅籍 → 繳 5% 營業稅 → 收入與所得無所遁形。

💡 這節課的真正收穫：商業洞察力

稅局 = 與時俱進的組織：傳統官僚機構透過年輕世代新思維，成功找出針對新興網路商業模式的課稅方法。
學稅法的目的不是算稅：而是看懂「商業邏輯」與國家機器的運作方式，理解做生意的不易之處。
日常觀察 = 商業啟蒙：夾娃娃機、網紅經濟 → 都是活生生的商業模型。當屬於自己的機會來臨，才能準確把握先機。

📍 屬地主義（消費地課稅）

課稅看的是「消費行為在哪裡發生」，不是看服務提供者在哪裡。

台灣觀眾在台灣用台灣網路看 YouTube → 消費在台灣 → 課台灣 5% 營業稅
台灣觀眾出國後看 YouTube → IP 顯示境外 → 外銷 0% 稅率
判定工具：網路 IP 位址 + 社群後台洞察數據

網紅節稅動機 = 將更多收入歸類為「境外」→ 反而將境內收入數據主動提交給稅局 → 成為稅局計算境外平台銷售額的最佳工具。
